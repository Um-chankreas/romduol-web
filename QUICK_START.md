⚡ Quick Start (5 Minutes)
Step 1: Get Your App ID (2 min)
Go to: https://console.agora.io
Sign up (FREE account)
Create a project
Copy your App ID
Step 2: Start the App (1 min)
bash
npm run dev

Open: http://localhost:5173

Step 3: Join a Channel (2 min)

First Tab (Teacher):

Channel Name: classroom-1
Your Name:    Teacher
App ID:       [paste your App ID here]

Click → Join Channel

Second Tab (Student):

Channel Name: classroom-1
Your Name:    Student 1
App ID:       [same App ID]

Click → Join Channel

✅ Both will see each other's video!

🎮 Controls
Action	Button
Toggle Microphone	🎤 Mute/Unmute
Toggle Camera	📹 Stop/Start Video
Leave Channel	Leave
🚨 Common Issues
Issue	Fix
Camera not working	Allow permissions in browser
Join failed	Check App ID, refresh page
No connection	Check internet, wait 2-3 sec
